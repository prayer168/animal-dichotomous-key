# 動物偵探

國小六年級自然科互動教材。直接用瀏覽器開啟 [index.html](index.html) 即可操作。將整個專案資料夾保存在同一個位置，離線使用時插圖會一併載入。

- **選圖卡**從空中飛行、貼地爬行、陸上步行、水中游動各 10 種動物中選 2～8 張，或載入現成題組。
- **二分法**選特徵，依序把動物分到「是」或「否」，核對後加入二分樹。用「查看分支」沿著問題逐層探索。
- **維恩圖**設定甲乙兩個條件，把動物依序放到四個區域。完成後可用相同的兩個條件對照二分樹。
- **辨認挑戰**沿著完成的二分樹回答特徵問題，找出未知動物。

課堂流程及圖卡使用方式見 [教師指引](teacher-guide.md)。圖卡是程式繪製的辨識示意圖。圖像原始程式為 `draw-animals.cjs`，可用 `node draw-animals.cjs` 重新輸出 SVG。網站本身無需安裝套件。
