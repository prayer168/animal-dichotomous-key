# 動物偵探

國小六年級自然科互動教材。直接用瀏覽器開啟 [index.html](index.html) 即可操作。保留整個專案資料夾即可離線載入圖卡。

- **抽圖卡**選 8～12 種動物，從空中、陸地、水中三組均衡抽樣。
- **二分法**選一個條件，把本輪圖卡拖到「是」或「否」，也可用點選放置。完成後核對，再切換圖卡查看答案。
- **維恩圖**從圖庫選兩種不同動物，即時比較本教材收錄的共同特徵和各自特徵。

課堂流程與教材來源見 [教師指引](teacher-guide.md)。圖卡是程式繪製的示意圖，可用 `node draw-animals.cjs` 重新輸出 SVG。網站本身無需安裝套件。
